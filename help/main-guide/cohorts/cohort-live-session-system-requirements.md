# 집단 라이브 세션에 대한 시스템 요구 사항

## Adobe Connect 준비

라이브 세션은 Adobe Connect을 사용하여 수행됩니다. 라이브 세션 중에 기술적인 문제를 방지하려면 다음 체크포인트를 따르십시오.

1. 이 [진단 테스트](https://training.adobeconnect.com/common/help/en/support/meeting_test.htm)를 실행하여 Adobe Connect이 시스템에서 제대로 작동하는지 확인하십시오.
1. Adobe Connect의 [기술 사양](https://helpx.adobe.com/adobe-connect/connect-tech-spec/12-10-technical-specifications.html)을 살펴보십시오.
1. 브라우저 또는 데스크탑 애플리케이션을 통해 Adobe Connect에 가입할 수 있습니다.
a) 데스크톱 앱이 이미 설치되어 있고 문제가 있는 경우 Adobe Connect 응용 프로그램을 제거하고 [여기](https://helpx.adobe.com/in/adobe-connect/connect-downloads-updates.html)에서 제공한 최신 버전을 사용하여 다시 설치하십시오.

캘린더 초대에서 개인화된 가상 회의실 링크를 찾을 수 있습니다. 교육 당일 수업 시작 5~10분 전에 링크 시작을 권장합니다.

## 하드웨어 요구 사항

- 키보드와 마우스를 갖춘 컴퓨터 또는 노트북
- 최적의 브라우저 성능을 위한 8GB RAM 이상
- 두 번째, 외부 모니터가 선호됩니다
- 최소 해상도 1280 x 768 픽셀
- 100Mbps 이상의 인터넷 연결

## 소프트웨어 요구 사항

- 권장 웹 브라우저는 Chrome 또는 Firefox입니다.
- [Adobe CX Enterprise](https://experience.adobe.com/)의 로그인 화면에 액세스하는 기능(아래 참고 사항 참조)
- 교육 중에 로그인 정보가 제공됩니다.
- 텍스트 편집기에 액세스
- 아카이브(.zip) 파일을 추출하는 프로그램
- [Adobe Reader](https://get.adobe.com/reader/)와 같은 PDF를 읽을 프로그램

>[!NOTE]
>
>로그인하지 마십시오. 회사의 네트워크가 링크를 차단하지 않고 브라우저에서 링크에 액세스할 수 있는지 테스트하기만 하면 됩니다. &quot;Adobe ID이 Adobe Experience Cloud 솔루션 계정에 연결되어 있지 않습니다&quot;라는 메시지가 표시될 수 있으며, 이는 예상되는 메시지입니다. 링크는 학습자가 수업 전에 어떤 것에도 액세스할 수 있도록 고안된 것이 아닙니다. 수업 첫 날 강사가 자격 증명을 제공하여 로그인합니다.
