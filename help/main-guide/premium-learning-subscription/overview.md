# Premium Learning 정보

구독 혜택, 갱신 옵션 및 학습 활용성 보고서를 살펴보십시오. 자세히 알아보려면 아래에서 연결된 페이지 이름을 선택하십시오.

* [구독 혜택 및 갱신](/help/main-guide/premium-learning-subscription/subscription-benefits-and-renewal.md): 구독에 포함된 내용과 학습 콘텐츠에 대한 액세스를 유지하는 방법에 대해 알아봅니다.
* [사용률 보고서 개요](/help/main-guide/premium-learning-subscription/utilization-reports/utilization-report-overview.md): 사용률 보고서에서 다루는 내용, 요청할 수 있는 사람, 포함된 내역 데이터를 확인합니다.
* [요약 시트 이해](/help/main-guide/premium-learning-subscription/utilization-reports/utilization-report-summary-sheet.md): 주요 지표, 등록 트렌드, 완료, 출석 및 인증 이해
* [등록 세부 정보 시트 이해](/help/main-guide/premium-learning-subscription/utilization-reports/utilization-report-enrollment-details-sheet.md): 학습자 등록 데이터, 과정 진행 상황, 중요 날짜 및 출석 세부 정보를 검토합니다.
