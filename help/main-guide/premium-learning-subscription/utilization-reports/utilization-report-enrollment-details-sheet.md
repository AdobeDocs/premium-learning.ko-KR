# 등록 세부 정보 시트 이해

## 등록 세부 정보 시트에는 무엇이 표시됩니까?

**등록 세부 정보** 시트는 요약 시트 뒤에 자세한 데이터를 제공합니다. 여기에는 학습자 정보, 과정 세부 정보, 진행 상황, 출석, 완료 상태, 주요 등록 및 수업 날짜가 포함됩니다.

학습 활용성 보고서의 &quot;등록 세부 정보&quot; 탭을 읽기 위한 빠른 참조입니다. 이 시트는 요약 시트 뒤의 데이터이며, 학습자 등록당 하나의 행입니다.

- **학습자/전자 메일** - 등록이 속한 사람.
- **양식** — 교육의 형식: 독립 실행형 ILT(라이브 강사 과정), 집단(다중 세션 프로그램) 또는 자습형/주문형
- **형식** — 전달 방법(예: 가상 교실 또는 자습형).
- **제품** - 과정에서 다루는 Adobe 제품. 한 과정에는 두 개 이상의 항목이 나열될 수 있습니다.
- **과정/교육** — 특정 과정 제목입니다.
- **인스턴스/세션** — 학습자가 등록한 특정 클래스 실행/세션(또는 예약된 세션이 없는 자동 진행형 콘텐츠의 경우 &quot;기본 인스턴스&quot;).
- **상태** - 학습자가 해당 과정에 있는 경우: 완료됨, 진행 중 또는 시작되지 않음.
- **진행률** — 십진수 완료 진행률(1 = 100% 완료, 0 = 시작되지 않음, 값의 경우 일부).
- **소요된 시간(분)** — 학습자가 과정에 로그인한 시간(분)
- **등록 날짜** - 학습자가 등록된 시간.
- **시작됨** - 학습자가 과정을 시작한 때입니다(시작되지 않은 경우 비어 있음).
- **기한** — 설정된 경우 목표 완료 날짜입니다.
- **완료됨** - 학습자가 완료한 날짜/시간(학습자가 완료된 경우).
- **기한 초과** — 마감이 완료되지 않고 경과되었는지 여부를 보여 줍니다.
- **클래스 배달 상태** — 클래스 자체가 아직 실행되었는지 여부입니다(배달됨, 예약됨 또는 진행 중). ILT/Cohort에만 적용되며, 자습에는 비어 있습니다.
- **ILT/집단 출석** — 학습자가 실시간 세션에 참여했는지 여부: 참석함, 부분 참석함, 표시 안 함, 예약됨 또는 진행 중. ILT/Cohort에만 적용됩니다.
- **클래스 시작/클래스 종료** — 라이브 세션에 대해 예약된 날짜입니다.
- **월-년** — 클래스/세션이 속하는 월입니다. 요약 시트의 &quot;월별 등록 트렌드&quot; 표에 제공되는 자료입니다.
- **표준 시간대** — 클래스가 실행된 표준 시간대입니다.

## 몇 가지 주의해야 할 사항

- 각 행은 한 명의 학습자가 아닌 하나의 과정 등록입니다. 3개의 과정을 가진 학습자가 3번 나타난다.
- 자가 진행식 행에는 항상 클래스 게재 상태, 출석, 클래스 시작/종료 및 시간대에 대한 공백이 표시되며, 이러한 열은 라이브 세션에만 적용됩니다.
