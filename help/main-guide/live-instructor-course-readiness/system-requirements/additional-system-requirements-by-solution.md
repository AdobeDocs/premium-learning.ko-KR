# 솔루션별 추가 시스템 요구 사항

## Adobe Experience Manager Edge Delivery Services 개발

개인 공용 GitHub 계정이 필요합니다.

## Adobe Experience Manager Sites

수업 기간 동안 Premium Learning의 Adobe Experience Manager 회사 계정에 액세스하여 과정 실습을 완료합니다.

Adobe Experience Manager 기술 과정의 경우 **[!DNL ReadyTech]**(이)라는 가상 컴퓨터 소프트웨어를 사용하십시오. 수업 전에 다음을 확인하십시오.

1. [성능 사전 검사 완료](https://adobe.instructorled.training/system-precheck)
1. 액세스 가능성 미리 검사를 완료하고 [[!DNL ReadyTech] 로그인 화면](https://axis.readytech.com/#/login)에 대한 액세스만 확인합니다(로그인 안 함).

## Adobe Campaign

Campaign 클라이언트는 Windows 전용 애플리케이션입니다. Campaign 클라이언트를 설치할 Windows 컴퓨터가 없는 경우 클래스 중에 **[!DNL ReadyTech]**(이)라는 가상 환경이 제공됩니다.

Windows 시스템 또는 소프트웨어 설치 기능이 없는 경우 다음을 확인하십시오.

1. [성능 사전 검사 완료](https://adobe.instructorled.training/system-precheck)
1. 액세스 가능성 미리 검사를 완료하고 [[!DNL ReadyTech] 로그인 화면](https://axis.readytech.com/#/login)에 대한 액세스만 확인합니다(로그인 안 함).

## Adobe Experience Platform

일부 기술 AEP 과정에서는 API 관련 활동에 **Postman**&#x200B;을(를) 사용합니다. 컴퓨터에 설치할 수 없는 경우 클래스 중에 가상 컴퓨터 **[!DNL ReadyTech]**&#x200B;을(를) 받게 됩니다.

소프트웨어를 설치할 수 없는 경우 다음을 확인하십시오.

1. [성능 사전 검사 완료](https://adobe.instructorled.training/system-precheck)
1. 액세스 가능성 미리 검사를 완료하고 [[!DNL ReadyTech] 로그인 화면](https://axis.readytech.com/#/login)에 대한 액세스만 확인합니다(로그인 안 함).
